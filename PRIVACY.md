# Privacy Policy

**English** | [简体中文](#隐私政策)

Course File Downloader for Blackboard (unofficial). Last updated: November 23, 2026.

This extension helps you download files from Blackboard courses you already have access to. It is an unofficial tool and is not affiliated with Blackboard or its owner. This policy explains what it does with information.

## Short version

The extension does not collect, send, sell, or share any personal data. Everything stays in your browser on your own computer.

## What the extension handles

- **Course information from Blackboard:** course names and IDs, folder and file names, and file links. The extension reads these from your own Blackboard site, using the page you already have open and signed in, in order to show you the file list and download the files you choose.
- **Settings and cache stored on your computer:** your language and save location choices, the list of files found by your last scan, and the permission handle for any folder you choose as a save location. These are kept in your browser's local extension storage and are never sent anywhere.
- **Your Blackboard sign-in:** the extension never reads, copies, or stores your password or cookies. Requests to Blackboard are made by your browser with your existing session, exactly as if you had opened the files yourself.

## What the extension does not do

- It does not send any data to the developer or to any third-party server.
- It does not use analytics, advertising, or tracking of any kind.
- It does not run code downloaded from the internet. All code is included in the extension package.
- It does not access websites other than your Blackboard site (domains under blackboard.com).

## Network requests

The only network requests the extension makes go to your Blackboard site and Blackboard's own file servers, to list course content and to download the files you selected.

## Your control

You can clear the stored settings and scan results at any time by removing the extension, which deletes all of its stored data. Files you download are saved only to the folder you choose.

## Changes

If this policy changes, the updated version will be published in this file with a new date. You can see every past version in the file's history on GitHub.

## Contact

Questions about privacy? Please [open an issue on GitHub](https://github.com/Yunyi1999/blackboard-course-downloader/issues).

# 隐私政策

[English](#privacy-policy) | **简体中文**

Blackboard 课件下载器（非官方）。最后更新：2026 年 11 月 23 日。

本扩展帮助你下载自己本来就有权访问的 Blackboard 课程文件。它是非官方工具，与 Blackboard 及其所有者没有任何关联。本政策说明扩展如何处理信息。

## 简而言之

本扩展不会收集、发送、出售或共享任何个人数据。所有内容都只保存在你自己电脑上的浏览器里。

## 扩展会处理什么

- **来自 Blackboard 的课程信息：** 课程名称和 ID、文件夹和文件名、文件链接。扩展通过你已经打开并登录的页面，从你自己的 Blackboard 站点读取这些信息，用来显示文件列表并下载你选择的文件。
- **保存在你电脑上的设置和缓存：** 你的语言和保存位置选择、上次扫描得到的文件列表，以及你所选保存文件夹的授权句柄。这些保存在浏览器的本地扩展存储中，不会发送到任何地方。
- **你的 Blackboard 登录状态：** 扩展不会读取、复制或保存你的密码和 cookie。向 Blackboard 发出的请求由你的浏览器使用现有的登录状态完成，与你自己打开这些文件完全一样。

## 扩展不会做什么

- 不会向开发者或任何第三方服务器发送数据。
- 不使用任何统计分析、广告或追踪。
- 不运行从网上下载的代码，所有代码都包含在扩展包内。
- 不访问你的 Blackboard 站点（blackboard.com 下的域名）以外的网站。

## 网络请求

扩展发出的网络请求只会发往你的 Blackboard 站点和 Blackboard 自己的文件服务器，用于列出课程内容和下载你选择的文件。

## 你的控制权

卸载扩展即可删除它保存的全部设置和扫描结果。你下载的文件只会保存到你选择的文件夹。

## 政策变更

如果本政策有变更，更新后的版本会连同新的日期发布在这个文件里，GitHub 上的文件历史可以看到以前的每个版本。

## 联系方式

对隐私有疑问，请 [在 GitHub 上提一个 issue](https://github.com/Yunyi1999/blackboard-course-downloader/issues)。
